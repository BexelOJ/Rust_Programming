2. Coding conventions
Let's maintain the same approach as our Java collection.

------------------------------------------------------------
Each exercise will have:
1. One complete Rust source file.
2. Necessary imports at the beginning.
3. A main() function.
4. Numbered sections using separator comments.
5. Individual operations demonstrated through code.
6. Aligned println!() output.
7. Expected output.
8. Explanation of memory management and ownership wherever relevant.
